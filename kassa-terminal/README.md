# Админка SBL — новая версия для VPS

**Версия от 23 ноября 2026 года.** Эта папка содержит актуальную кассу и админку, работающую через собственный REG.RU VPS.

- Backend: `https://31.31.207.216/coffee`.
- Вход сотрудников, чтение заказов и изменение статусов используют Auth/REST этого VPS.
- В режиме VPS обновления заказов выполняются опросом API; облачный Realtime не требуется.
- В комплекте: касса, каталог и стоп-лист, публикации и промокоды.

Исходники этой версии сверены побайтно с админкой, обслуживаемой на ПК владельца по `http://127.0.0.1:8098/`. Владелец подтвердил на Samsung регистрацию аккаунтов и прохождение заказов через VPS и кассу. Это не утверждение о завершении всех оставшихся работ по миграции.

## Запуск

Из корня репозитория:

```sh
python -m http.server 8098 --bind 127.0.0.1 --directory kassa-terminal
```

Открыть `http://127.0.0.1:8098/`. Нужен доступ в интернет до VPS. Не открывать HTML через `file://`.

## Конфигурация и доступ

`SUPABASE_URL` и `SUPABASE_KEY` в `index.html` указывают на VPS. Названия переменных и библиотека Supabase JS сохранены для совместимости с Auth/PostgREST API; адрес backend в этой версии — собственный VPS.

В браузере используется только публичный ключ с ролью `anon`. Доступ сотрудника проверяет сервер по его сессии и SQL/RLS. Пароли, `service_role`, серверные ключи, дампы и `.env` в эту публикацию не входят. При смене VPS заменить URL и соответствующий публичный ключ вместе.
