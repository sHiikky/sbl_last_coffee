# Перед отправкой в App Store — что сделать на VPS

1. Применить миграцию `supabase/migrations/20261124100000_account_self_deletion.sql` (от владельца таблиц, обычно postgres).
2. Развернуть функции: `delete-account` (новая) и `start-waitcall` (демо-вход).
3. Демо-вход для проверяющих Apple: задать секрет `REVIEW_DEMO_PHONE=+7XXXXXXXXXX` (отдельный номер, не чей-то реальный).
   Вход с этим номером проходит без звонка за несколько секунд. После одобрения — удалить секрет.
   В App Store Connect → App Review Information указать: «Введите номер +7…, отметьте согласие,
   нажмите „Получить номер для звонка“. Звонить не нужно — вход выполнится автоматически».
4. Проверить автопродление HTTPS-сертификата (истекает 29.11).
5. Проверка удаления: войти тестовым аккаунтом → Профиль → «Удалить аккаунт и данные» → пользователь исчезает из auth.users, выданные заказы остаются без имени/телефона.

На iPhone вход через Яндекс скрыт (правило 4.8), iPad выключен.
