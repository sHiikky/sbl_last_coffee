## ТЕХНИЧЕСКАЯ ЧАСТЬ

### 1. Исходный код
GitHub: https://github.com/sHiikky/sbl_last_coffee, ветка `main`. Доступ к репозиторию даст владелец — пришли свой GitHub-логин.

Проект на Expo SDK 58 (React Native 0.88, React 19.3). Это нативное приложение, а не сайт.

### 2. Файл .env / production-переменные
Отдельный `.env` для сборки не нужен: все production-значения уже прописаны в `eas.json`, профиль `ios-store`.
- Сервер: `EXPO_PUBLIC_SUPABASE_URL=https://31.31.207.216/coffee` (собственный сервер кофейни) и публичный ключ `anon`.
- Вход по номеру телефона (звонок) включён. Push выключен, режим администратора выключен.
- Секретов в приложении нет.

Для локального запуска: `cp .env.example .env`, затем `npm start` (Expo Go для SDK 58) или `npm run web`.

### 3. Команда сборки и папка с результатом
`npm run build` и папки `dist`/`build` нет: iOS-сборка делается через EAS Build, результат — `.ipa` в облаке Expo.
```sh
npm ci
npx eas build -p ios --profile ios-store      # подписанная сборка для App Store (.ipa)
npx eas submit -p ios --profile production     # отправка в App Store Connect
```
- `bundleIdentifier`: `com.shikky.sbl`. Версия `1.0.0`, buildNumber `1`. Только iPhone (`supportsTablet: false`).
- Expo-проект: owner `shikkyy`, projectId `00f1af5f-48f9-418b-aa4f-233eead9fd9a`. Нужен доступ к этому Expo-аккаунту или перенос проекта.
- Нужен платный Apple Developer аккаунт. Сертификаты и профиль EAS создаст сам при первом `eas build`.

### 4. Иконка и сплэш-скрин

### 5. Нативные функции
Плагины уже подключены в `app.json`, ничего добавлять не нужно.
- **Камера** — не используется.
- **Микрофон** — не используется.
- **Push-уведомления** — модуль подключён, но в этой версии выключены.
- **Геолокация** — только «при использовании», по кнопке на карте кофейни; в фоне не используется.
- **Фото-галерея** — выбор фото профиля; фото хранится только на телефоне.
- **Прочее** — вибрация (haptics) и открытие карт в Safari / приложении карт.

Privacy manifest и `usesNonExemptEncryption: false` (шифрование не нестандартное) уже прописаны в `app.json`.

### 7. Полное описание
```
SBL — приложение кофейни в Томске. Закажите напитки и десерты из приложения и заберите заказ в кофейне.

КАК ЭТО РАБОТАЕТ
• Выберите напитки и десерты в меню с фотографиями и описанием.
• Добавьте по вкусу альтернативное молоко, сироп и другие добавки, оставьте пожелание бариста.
• Отправьте заказ — кофейня начнёт его готовить.
• Оплата при получении в кофейне — в приложении платить не нужно.
• Следите за статусом в приложении: подтверждён, готовится, можно забирать.

СЕРИЯ SBL
Делайте заказы несколько дней подряд — за каждые 10 дней серии мы дарим десерт. Прогресс серии виден в приложении.

БОНУСЫ И КЭШБЭК
Копите бонусы за покупки и тратьте их на следующие заказы. Баланс и уровень карты — в профиле.

УДОБНО
• Избранное: сохраняйте любимые напитки.
• История заказов с составом и суммой, повтор заказа в пару касаний.
• Карта и маршрут до кофейни: проспект Ленина, 72. Работаем ежедневно с 11:00 до 20:00 по томскому времени.
• Поделитесь понравившимся напитком с другом.

ВХОД
Вход по номеру телефона: подтверждение одним звонком, без кодов и паролей. Меню можно смотреть без входа.
Аккаунт можно удалить прямо в приложении.

Мы небольшая кофейня и делаем приложение для своих гостей. Если что-то не работает, напишите нам — контакты есть в разделе «Политика и контакты».
```
