# SBL coffee — данные для сборки и публикации в App Store

## Техническая часть

**Исходный код:** https://github.com/sHiikky/sbl_last_coffee (ветка `main`). Нужен доступ к репозиторию — владелец добавит ваш GitHub.

**Что это за проект:** Expo SDK 58 (React Native 0.88, React 19.3) — нативное приложение, НЕ веб-сайт.
Команды `npm run build` и папки `dist` нет: iOS-сборка делается через EAS Build.

```sh
npm ci
npx eas build -p ios --profile ios-store      # подписанная сборка для App Store (.ipa)
npx eas submit -p ios --profile production     # отправка в App Store Connect
```
- `bundleIdentifier`: `com.shikky.sbl`, версия `1.0.0`, buildNumber `1`, только iPhone (`supportsTablet: false`).
- Expo-проект: owner `shikkyy`, projectId `00f1af5f-48f9-418b-aa4f-233eead9fd9a` (нужен доступ к Expo-аккаунту или перенос проекта).
- Нужен Apple Developer аккаунт (платный); EAS сам создаст сертификаты и профиль при первом `eas build`.

**Переменные (.env):** отдельный файл не нужен — все production-значения уже прописаны в `eas.json`, профиль `ios-store`:
`EXPO_PUBLIC_SUPABASE_URL=https://31.31.207.216/coffee`, публичный ключ `anon`, вход по звонку включён,
Вход только по номеру телефона (звонок), push выключен, режим администратора выключен. Секретов в приложении нет.
Для запуска локально: `cp .env.example .env`, `npm start` (Expo Go для SDK 58) или `npm run web`.

**Иконка и заставка:** в проекте — `assets/brand/app-icon.png` (1024×1024, без прозрачности), `assets/brand/splash-full.png`.

**Нативные функции** (плагины уже подключены в `app.json`):
- Геолокация — только «при использовании», по кнопке на карте кофейни; фон отключён.
- Фото-галерея — выбор фото профиля (хранится только на устройстве); камера и микрофон НЕ используются.
- Push-уведомления — подключён `expo-notifications`, но в этой версии выключены.
- Вибрация (haptics), открытие ссылок/Safari для карт.
- Privacy manifest (required reason API) и `usesNonExemptEncryption: false` уже в `app.json`.

**Для проверки Apple (App Review Information → Notes):**
Демо-вход: номер `+70000000001` → отметить согласие → «Получить номер для звонка». Звонить не нужно, вход выполнится сам за несколько секунд.
Удаление аккаунта: Профиль → «Удалить аккаунт и данные». Оплата — при получении в кофейне (физический товар, без покупок в приложении).
