ВКЛЮЧЕНИЕ PUSH ПОЗЖЕ
Настроить FCM/APNs credentials для проекта EAS; Expo Go не подтверждает работу push.
Установить клиентский флаг и ORDER_PUSH_ENABLED=true на сервере.
ORDER_PUSH_WORKER_SECRET — отдельный серверный секрет; при enhanced push security
также настроить EXPO_ACCESS_TOKEN только в серверных Secrets.
Для устойчивой доставки запланировать регулярный серверный POST-вызов worker
с телом {} и заголовком x-order-push-secret: <ORDER_PUSH_WORKER_SECRET>, чтобы
обрабатывались отложенные повторные попытки и receipts даже без открытой кассы.
Затем проверить выдачу разрешения, отказ, выключение, готовность закрытого приложения,
нажатие уведомления, переключение пользователя и DeviceNotRegistered.
Касса вызывает worker после статуса и не зависит от успеха отправки; очередь сохраняется.
