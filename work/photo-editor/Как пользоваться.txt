SBL — локальный редактор размещения фотографий

Редактор не загружает фото в Supabase, не переименовывает оригиналы и не
меняет базу. Он читает только публичные поля доступных позиций каталога:
название, цену, категорию и ссылки на изображения. Пользователи, заказы,
контакты и ключи СБИС здесь не используются.

1. Откройте редактор через локальный HTTP-сервер, который запускает разработчик.
   Не открывайте index.html двойным щелчком: браузер может ограничить скрипты.
2. Выберите напиток или блюдо. Поиск и фильтр помогут найти нужную позицию.
3. Переключайте «Карточка товара» / «Меню»: у каждого вида свои настройки.
4. Отрегулируйте масштаб и сдвиг. Для напитков обычно подходит «Показать
   целиком». Можно включить направляющие и проверить компактный экран.
5. Черновик автоматически сохраняется в этом браузере. Это не изменение
   приложения. Очистка данных браузера удалит локальный черновик.
6. Нажмите «Скачать настройки» и прикрепите полученный JSON-файл в чат.
   Разработчик проверит файл и встроит настройки в data/photo-compositions.json.
7. Скачанный JSON можно снова открыть через «Открыть настройки». Он
   объединяется с текущим черновиком: совпавшие позиции обновляются,
   остальные локальные настройки сохраняются.
   Чтобы продолжить ранее переданную работу на другом компьютере, сначала
   откройте последний скачанный файл.

Экспорт содержит только позиции этого локального черновика. При встраивании
Разработчик объединяет их с уже встроенными настройками ПО UUID, сохраняя другие
позиции. «Сбросить» добавляет в JSON явные стандартные параметры: так можно
отменить ранее встроенную композицию. «Убрать позицию из черновика» лишь
убирает её из будущего экспорта и не сбрасывает уже встроенное в приложение.

Файл содержит UUID позиции, название для удобства, исходный URL и SHA-256
этого URL, а также параметры detail/card. Отпечаток относится к АДРЕСУ фото,
а не байтам файла. Замена файла по тому же URL не обнаруживается: при новой
версии фотографии используйте новый URL. Для изменённого URL или скрытой
позиции настройки не импортируются/не экспортируются, чтобы не применить
старую композицию к другому изображению. Они остаются в локальном черновике.

Параметры версии 1:
- type: sbl-photo-composition; projectRef: vxefueynagwuavlyeiqc;
- products: массив записей с id, name, sourceUrl, sourceFingerprint;
- detail и card: { fit, zoom, offsetX, offsetY };
- fit: contain / cover; zoom: 0.5–1.8; offsetX/offsetY: −35…35 процентов;
- масштаб относительно центра; сдвиг в процентах РАМКИ, за пределами
  масштабирования. detail aspectRatio=1/1.05; card aspectRatio=1.
- стандартно detail: contain, 0.90, 0, 0; card: contain, 1, 0, 0.

Редактор меняет только размещение. Он не удаляет фон, не обрезает белые поля
внутри исходного файла и не улучшает качество/содержание самой фотографии.
Превью использует белый фон и ту же геометрию трансформации, что приложение;
остальные части карточки показаны схематично. Проверка на телефоне остаётся
последним этапом после встраивания настроек.
