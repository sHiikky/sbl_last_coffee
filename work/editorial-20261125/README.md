## Серверный шаг

Из обычного CMD Windows запустить migration-stage-a-20261108/apply-editorial-updates.cmd.
Пакет сделает свежую копию установленным проверяющим backup-tool, применит обе SQL-миграции в одной транзакции и точечно изменит start-waitcall в КОПИИ действующего runtime. SMSC host/native transport, callback, секреты и остальные обработчики сохраняются. Проверяется совпадение активного ExecStart; при несовпадении исходника установка прекращается до изменения БД. Перезапускаются только функции кофейни, лимиты и guard неизменны.

При сбое после изменения runtime возвращается прежний unit. Аддитивная схема автоматически не удаляется, чтобы не уничтожить новые публикации. Артефакт отчёта укажет schemaApplied/handlerRolledBack; повторять частично завершённую установку без разбора нельзя. Старая версия приложения продолжает отправлять register по умолчанию. Новый клиент с login требует новый backend; переключать локальный preview после успешного серверного отчёта.

После успешного отчёта: опубликовать локальный web export на 8099, проверить реальный вход и тестовый анонс сотрудником. В этой работе коммит/push/APK не выполнялись.
