Карта SBL — уточнение от 2026-10-29

Внешний вид страницы CafeLocation сохранён: заголовок, адрес, превью, часы,
самовывоз/оплата и основной CTA. Превью открывает полноэкранную интерактивную
карту внутри приложения. Изменение камеры, масштаб, возврат к точке и
одноразовое определение места по отдельной кнопке. Фоновой геолокации нет.
Координаты пользователя не сохраняются в БД/AsyncStorage и не добавляются
в исходящие ссылки маршрута; навигатор получает только публичную точку SBL.

Первичные источники:

1. OSM Foundation — Attribution Guidelines / Interactive maps:
https://osmfoundation.org/wiki/Attribution_Guidelines
Допустим угловой credit. Может автоматически сворачиваться через пять секунд,
если источник/лицензия остаются доступны через информационную кнопку.
Поэтому отдельная нижняя полоса убрана; начальный © OpenStreetMap в углу
карты сворачивается через 5.5 секунд в доступную кнопку информации.
Полностью скрывать происхождение карты нельзя. Панель информации ведёт к
https://www.openstreetmap.org/copyright (ODbL и все источники).

2. OSM Standard tile policy:
https://operations.osmfoundation.org/policies/tiles/
HTTPS, понятный User-Agent на native, web Referer, memory-disk cache.
Только тайлы текущего видимого viewport, без offline download и prefetch.
Сервис best effort; существующий fallback сохраняет адрес и навигаторы.

3. 2ГИС — актуальные deeplinks:
https://help.2gis.ru/question/razrabotchikam-zapusk-ideystviya-vmobilnom-prilozhenii-cherez-deeplink
HTTPS предпочтителен: приложение при наличии, веб при отсутствии.
geo/lon,lat — произвольная точка; directions/points/|lon,lat — маршрут
к точке Б без передачи точки А. Использован актуальный формат,
не legacy routeSearch. Тип транспорта выбирает сам пользователь.

4. Яндекс — официальный пример ссылок маршрута:
https://yandex.ru/routing/doc/en/vrp/examples-svrp
https://yandex.ru/maps/?mode=routes&rtext=~56.481399,84.94905
Публичная карточка SBL (сверенные ранее координаты):
https://yandex.com/maps/org/sbl/96849739091/

5. Expo Location:
https://docs.expo.dev/versions/latest/sdk/location/
Используется совместимая с Expo54 версия из bundledNativeModules,
не версия latest SDK. requestForegroundPermissionsAsync + одноразовый fix
через watchPositionAsync, который сразу удаляется после первой координаты,
при таймауте, закрытии карты или уходе приложения в фон. Никаких background
permissions/tasks. Native permission plugin применяется только новой сборкой.

Сравнение доступных публичных сценариев, не технической реализации чужих APK:

6. Дринкит — официальный сайт:
https://guest.drinkit.ru/ru
Карта кофеен и сценарий заказа по пути. Применимо для SBL: конкретная точка,
минимум препятствий между адресом и маршрутом. Внутренний SDK чужого приложения
из публичного сайта не устанавливается и не утверждается.

7. Вкусно — и точка — официальная карта предприятий:
https://vkusnoitochka.ru/restaurants/map
Карта, адрес, фильтры сетевых точек. Для единственной точки SBL сетевые фильтры
не добавлялись: сохранён существующий экран с одним адресом и действием маршрута.
Страница приложения дала403 при чтении, поэтому её текущий экран геолокации
не выдаётся за лично проверенный. Образец отдельного выбора карты/геопозиции
реализован самостоятельно с учётом запросов владельца.

Проверено локально: геометрия панорамирования/anchor zoom/тайлов и fit;
доступы геолокации denied/disabled; первый fix/timeout/cancellation/late watch.
Физический GPS, native pinch и открытие установленных навигаторов требуют телефона.
